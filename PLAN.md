# rs-mmap development

Version 0.3 develops file snapshots, OS-verified immutable mappings and typed persistence over memmap2. The API, supported platforms and migration from 0.2 are documented in the [README](README.md). The [0.2.3 source and benchmark harnesses](https://github.com/codixor/rs-mmap/tree/v0.2.3) preserve the original native backend and its performance measurements.
